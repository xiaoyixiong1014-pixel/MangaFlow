# 漫序 MangaFlow · 项目介绍

## 一、项目背景

我要介绍的项目叫漫序，是一款面向内容创作者与机构一体化的AI漫剧生成平台。

做这款项目是为了解决当前漫剧制作长期受周期长、门槛高、角色形象易崩三重制约，而现有 AI 工具把文本、图像、视频、配音割裂在不同产品里，串不成闭环。而漫序则是采用「流水线 + 画布」双引擎承接批量交付与自由探索，以多智能体编排为中枢串起四类模型，下面我将介绍的核心功能模块：

## 二、核心功能模块

### 1. 剧本创作

首先是剧本创作，其作用是一句话或小说入稿，四段式产出可分集正文。我是采用LangGraph 子图编排故事设定、角色、大纲、正文四阶段，段间用 `interrupt` 做人工确认、PostgreSQL 检查点支持断点续跑；正文用 `Send` 并行分发多集再 reduce 汇总。剧本落 JSONB 并带字段来源标记，AI 只出片段化 diff，不覆盖用户手改内容。



### 2. 资产管理

其次就是资产管理，对于角色、场景和道具资产，只有等用户生成并锁定后约束下游所有生成。采用视觉模型抽结构化面部档案并向量化，新图与主形象算余弦相似度，低于阈值自动重生成；向量走 pgvector 影子列加 ivfflat 索引，扩展不可用时自动回退应用层计算。



### 3. 内容生成

接着就是内容生成，我把他分为了关键帧、配音、视频、合成四步生产。全部走异步任务队列（`SKIP LOCKED` 抢占、指数退避重试、死信重放、SSE 推进度），积分按冻结—扣费—退款幂等闭环；模型调用统一经路由中心按优先级解析渠道并自动降级。视频出片后用 Wav2Lip 以配音驱动对口型，成片由 ffmpeg 单条滤镜链完成转场、字幕、混音与水印。



### 4. AI 画布

以上给描述的是一整套流水线中的功能，除此之外还有个就是AI画布。用户可以设置好节点并连线成图，自由编排与精修。节点—边图存 PostgreSQL，执行时拓扑排序成 DAG，支持全量、dirty（只跑脏节点）、单节点三种模式，结果回写后自动把下游标脏；助手用大模型输出节点与连线 JSON 直接落成子图，插件与 MCP 工具作为集成节点接入。



### 5. 多智能体编排中枢

最后就是多智能体编排中枢，统一入口承接意图，按需调度各领域能力。采用LangGraph StateGraph 加 Supervisor 意图路由，域智能体只通过共享状态交接；PostgresSaver 落检查点支持续跑与阶段回退，人工确认用 `interrupt` / `Command(resume)`，批量任务用 `Send` 做 map-reduce，审核与一致性封装为子图复用。



## 三、一句话收尾

漫序不是一个"AI 出图工具"，而是一条可确认、可重生成、可回退的漫剧生产线。以上就是我的项目，从需求到部署上线均为我一人完成。
