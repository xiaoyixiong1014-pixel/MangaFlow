# 漫序 MangaFlow · 项目介绍（5 分钟讲述版）

## 一、项目背景

漫剧（动态漫画）已是短视频平台的主流内容形态，但制作有三个硬痛点：**周期长成本高**，编剧、分镜、原画、配音、剪辑多工种串联，一集要几周；**门槛高**，要同时会编剧、会画、会剪，有创意的人做不出成片；**角色一致性难控**，多镜头多剧集下形象容易崩，返工率极高。而现有 AI 工具各自割裂，文本、图像、视频、配音分散，没有统一资产约束，串不成闭环。

漫序是面向创作者与机构的**一体化 AI 漫剧生产平台**，双引擎承接两类诉求：**Studio 流水线**做五阶段强约束生产，可批量交付；**Canvas 画布**做无限编排，可自由试错。两者共享同一套资产、模型、计费与审核底座，并双向联动——分镜可投递画布精修，画布产物可沉淀回资产库。

目标很直接：把一集的制作周期从数周压到**小时级**，综合成本降 **70%** 以上。

技术主线只有一条：**以多智能体编排为中枢，把文本、图像、视频、语音四类模型串成一条"每步可确认、可重生成、可回退"的流水线**。后面每个模块，都是这条主线在不同环节的落地。

---

## 二、核心功能模块

### 模块一 · 剧本创作：从一句话到可分集正文

支持三种输入（一句话、txt/epub 小说、粘贴大纲），走四段式工作台：**故事设定 → 角色班底 → 分集大纲 → 逐集正文**。每段可单独重生成、手动改，确认后才进下一步；正文的 AI 优化只出片段化建议，不整篇覆盖用户改过的内容。

实现上，这一段是一条 **LangGraph 剧本子图**：四个阶段是四个节点，中间插三个 `interrupt` 人工确认点，确认后从断点恢复；写正文时用 `Send` 把 N 集并行分发给写手节点再汇总。每阶段落一次 PostgreSQL 检查点，断网、切页都能续跑。

结构化是这层的关键：剧本按场次落 JSONB，字段带"来源"标记，用户改过的字段下游不会被覆盖；改编小说切 faithful 档，还会校验"名单外新造角色"。**先定角色再写戏**，解决了"生成完再回头抽角色"的顺序错位。

### 模块二 · 资产管理：把角色"锁"下来

从剧本提取角色、场景、道具，批量出定妆照（正/侧/半身三角度）、多套造型与场景概念图；满意后**一键锁定**，锁定即成为下游所有生成的强制约束。

一致性被做成可度量约束：定妆照出来后用视觉模型抽一份**结构化面部档案**（脸型、发型、发色、瞳色等十余项）并向量化，新图再抽一次算余弦相似度，低于阈值自动重生成；向量检索走 pgvector，环境不支持时自动退回应用层计算。

### 模块三 · 分镜设计：把剧本翻译成镜头语言

一键拆成分镜表，每镜含景别、运镜、时长、对白、画面描述，自动绑定出场角色与道具；支持拖拽排序、拆分合并、全字段编辑，并做时长与资产绑定校验，可导出 Excel/PDF。

拆镜按剧集顺序读取全部剧本行，逐场次让大模型生成 1~3 个镜头，失败时按规则降级出镜；绘图提示词由系统融合"角色资产 + 场景资产 + 运镜信息"自动拼装，不懂影视语言也能出专业镜头。

### 模块四 · 内容生成：关键帧、配音、视频、口型

生产页按"关键帧 → 配音 → 视频 → 合成"四步走，支持单镜、批量、全量三种模式，每镜可单独重生成，提交前给出积分预估。

所有生成都是**异步任务**，页面不阻塞：优先队列抢占 + 失败指数退避重试 + 死信队列可重放，进度用 SSE 推前端；计费走"冻结—扣费—退款"幂等闭环，平台故障平台承担。

模型调用统一走**模型路由中心**：业务只认"逻辑模型"，下层按优先级解析物理渠道（图像视频走 Agnes、文本走 DeepSeek 带兜底、配音走百炼 TTS），实时回写健康度、故障自动降级，链尾挂本地兜底。

最新补的一环是**口型同步**：视频出来后用配音音频驱动 Wav2Lip 逐帧对齐口型，本地 CPU 两遍流式处理压内存，无人脸或模型缺失自动降级为原视频，不阻断主流程。

### 模块五 · 审核与发布：合规出片

成片预览、分镜级回退重生成、多分辨率与三画幅导出、带有效期和密码的分享链接、隐形溯源水印。

审核是**三级闸门**：敏感词分级机审（严禁级直接拦截退款）→ 大模型复核 → 视觉审核，违规按累计次数分级处罚（限流、禁用）。合成用 ffmpeg 一条滤镜链完成转场、字幕烧录（支持双语）、BGM 混音与水印，任一环节失败逐级降级但成片照常产出。

### 模块六 · AI 画布：流水线之外的另一半

无限画布拖入 12 类节点（文本、生成、视频、资产引用、分镜、合成、逻辑、插件、MCP 工具等），连线成 DAG 执行；右侧助手可用自然语言直接生成子图，分镜也能投递进来精修后回填。

后端维护节点—边图做拓扑执行，支持全量、增量（只跑脏节点）、单节点三种模式，结果写回后自动把下游标脏，避免重复烧钱；插件与 MCP 工具都能挂成节点，走"安装 → 审核 → 授权 → 调用"。

**贯穿所有模块的中枢**是统一创作 Agent：Supervisor 识别意图，路由到剧本、资产、分镜、生成、审核、画布等领域智能体；共享状态用 reducer 合并，长任务用检查点续跑，需人确认处 `interrupt` 挂起、`Command(resume)` 恢复，批量用 `Send` 做 map-reduce。**流水线和画布，本质就是这套编排能力的两种前端形态。**
